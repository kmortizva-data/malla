Get MODSIM running without grief

Why this matters

Canvas pages 0.5 and 1.3 say it plainly: most "MODSIM ate my work" moments in this course come down to three settings. Your own Feed Stream dialog showed the first symptom on 4 September: the solids feed rate read 600,0000 and the percent solid 2,00, with commas. Windows was speaking Swedish or Spanish to a program that only understands the decimal point. Fifteen minutes here, once, and every later exercise gets easier.

Two programs are in play. Classic MODSIM 3.6.12 is the reference (folder C:\Program Files (x86)\MODSIM3_6_12_Student, manual MANUAL_V36.pdf in the course material). The MODSIM-GUI beta on your desktop is the course's experimental front end: it opens the same PAK files, saves its own .mpd project, and exports graphs directly. Results that differ between the two are worth a screenshot and an e-mail to the teacher, with the PAK attached; the course asks for exactly that kind of check.

Windows decimal point

Watch out

MODSIM only understands the decimal point: 3.14, never 3,14. With a comma, numbers are read as garbage without any error message, and the run "succeeds" with nonsense inside.

1

Switch the decimal symbol to a point, for your user

ClickWindows Settings > Time & language > Language & region > Regional format > Change formats (or "Additional settings") > Decimal symbol: type a point
ExpectEvery number field in MODSIM-GUI and classic MODSIM now shows 600.0000 and 2.00
WhyThe simulation engine (MODSIM.DLL, Fortran) parses text with a point; the GUI shows numbers with whatever Windows says, so a comma on screen is the warning light
Change it before you start the program, and keep it while MODSIM runs. Excel and other programs follow the same setting; a comma-based CSV export will now use points

Quick check in PowerShell, no admin rights needed:

prints
tag: PowerShell
(Get-Culture).NumberFormat.NumberDecimalSeparator

The answer must be a point. If it is a comma, the setting above has not taken effect yet (sign out and in again).

The MODSIM work area

Classic MODSIM reads and writes in its own program folder unless told otherwise. The course's advice: point the environment variable MODSIM at a folder you control.

2

Create a work area and tell MODSIM about it

ClickCreate C:\Temp\MODSIM\ ; then Windows Settings > System > About > Advanced system settings > Environment Variables > User variables > New: name MODSIM, value C:\Temp\MODSIM\
ExpectAfter a restart of MODSIM, its job files (.JOB and dozens of small files) appear in C:\Temp\MODSIM\ and not in Program Files
WhyProgram Files is protected and shared; a work area you own can be cleaned, backed up and zipped
Keep the trailing backslash in the value. On the LTU terminal server the work area is H:\MODSIM\ and is already set

The same thing from PowerShell, one line each:

prints
tag: PowerShell
New-Item -ItemType Directory -Force C:\Temp\MODSIM
[Environment]::SetEnvironmentVariable("MODSIM", "C:\Temp\MODSIM\", "User")

The MODSIM-GUI needs none of this: it is portable, keeps its settings in your user registry, and saves the .mpd wherever you choose. Choose the course folder: Simulation of Mineral Processing\Projects MODSIM\.

Saving habits

  • Save as PAK, often. A classic MODSIM project is a swarm of small files. After every significant step pack it into one .PAK, move the PAK to your course folder, and clean the work folder. The PAK is also what you submit and share.
  • One file per milestone. Ex1_base.PAK, Ex1_cut85.PAK, Ex1_cut90.PAK; never overwrite a PAK that a figure in your report depends on.
  • Figures. Classic MODSIM exports flowsheets and size-distribution plots as PostScript; convert to EMF (vector, stays sharp) before inserting into the report. The GUI exports graphs directly, no detour.
  • Auxiliary Excel workbooks from Canvas 0.5 (Lin_Log.xls, Gaudin.xls, RRS.xls, Mineral.xls) estimate RRS parameters from sieve data and compute mineral grades from element analyses; they are in the course material folder.
  • When MODSIM misbehaves: check the decimal setting first, then that the work area exists and is writable, then ask in the Q&A forum with a screenshot.

The MODSIM-GUI project wizard

The GUI defines the material in one dialog with tabs, walked left to right: Components · Grades · Properties · Liberation · Washability · Streams · Size_Conv. · Review. Two tabs decide whether a screening job makes sense.

Note

Sizes in the GUI are in metres in this tab and in micrometres in the PSD table: 600 mm is 0.6 m here and 600000 µm there. Write the unit next to every number you type.

What each Review message means and where it is fixed:

MessageWhereFix
Material type is not selectedComponentspick Minerals (one ore, no assays needed for screening)
Feed stream "? → Screen-1" has no material definitionStreams > feed rowopen the Feed Stream dialog, enter rate, percent solid and the PSD, press OK

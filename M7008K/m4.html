Element-to-mineral conversion

A concentrator separates minerals . A drill core is described by elements , because chemical assays are cheap enough to run on every metre of every hole while quantitative mineralogy is not. A geometallurgical block model that carries only grades therefore carries the wrong variable.

Assignment 1 · pass / fail · individual hand-in, one Excel file

Element-to-mineral conversion

Due: w39 derived

What a pass requires
  1. All seven sheets present, in order, and readable by someone who did not build the workbook
  2. The mineral compositions and densities recorded, with the source stated
  3. The rounds explicitly documented: a reader can see which assay solved which mineral
  4. Assumptions written down where the chemistry does not determine the answer, with a justification (the part that is actually being examined)
  5. Residuals reported and commented on: where the fit is poor, you say so and offer an explanation
  6. A stacked bar chart against depth that can be read: axes labelled, minerals distinguishable, depth increasing in a sensible direction
